나는 비개발자이고 해커톤(neatHack)용으로 "Brief Buddy"를 만들려고 해. 통역사가 통역 일 전에 준비하는 걸 도와주는 작은 웹앱이야.

규칙: 작게, 끝까지 돌아가게. 기능은 아래 3개만. 로그인, DB, 결제, 음성은 만들지 마. 저장은 브라우저 localStorage만. 모든 단계에서 나한테 쉬운 말로 설명하고, 한 단계씩 실행해서 돌아가는 걸 확인하면서 진행해.

사용자: 한국어-영어 프리랜서 통역사. 통역 일 전날 밤 20분 안에 준비를 끝내고 싶어.

기능 1 - 입력: 회사명, 행사/미팅 주제, 통역 방향(한영/영한), 선택으로 참고 자료 텍스트 붙여넣기.
기능 2 - 브리프 생성: LLM이 한 화면짜리 브리프를 만들어. 구성: (a) 회사/업계 한 줄 요약 (b) 꼭 알아야 할 배경 5줄 (c) 용어집 20~30개 (영어, 한국어, 한 줄 설명) (d) 예상 대화 흐름 (e) 현장에서 쓸 통역 표현 10개. 모르는 건 지어내지 말고 "확인 필요"라고 표시해.
기능 3 - 연습: 용어집으로 플래시카드 퀴즈(영어 보고 한국어 말하기, 반대도). 맞음/틀림 체크하면 틀린 것만 다시 나와.
보너스(시간 남으면): 브리프를 인쇄/PDF로 저장.

기술: React + Vite 같은 가장 간단한 구성. LLM API 키는 .env에 두고 코드/깃허브에 올리지 마. 먼저 기능 2를 하드코딩 샘플 데이터로 화면부터 띄우고, 그다음 API를 연결해.

첫 실제 케이스(샘플 입력): 쿼드비(Quad.BE) - 화장품 패키징 플랫폼 회사 MOLDWORK 관련 통역. 월요일에 실제로 씀.
