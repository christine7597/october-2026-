A WORKFLOW span is the trace ROOT of a meaningful unit of AI work. Root ONLY entry points that (directly or transitively) reach an LLM/agent/tool/retriever — a chat / generate / analyze / agent-run / model-calling consumer. AUTO-ROOT (important): the provider wrappers (`neatlogs.wrap(client)` in Python, `wrapOpenAI`/`wrapAnthropic`/`wrapGoogleGenAI`/… in TypeScript) and Python `instrumentations=[...]` now open a WORKFLOW root AUTOMATICALLY when a provider/LLM call would otherwise be parentless — so a lone wrapped call does NOT orphan and renders on its own.
