- 제품: MOLDWORK(몰드웍) — 화장품 패키징 개발을 디지털로 옮기는 "패키징 DX 플랫폼". 회사 표현: "마지막 아날로그(the last analog sector)를 디지털로".
- 기능 흐름: 전 세계 화장품 용기 패키징 검색 → 부품 조합 → 3D 시뮬레이션 → 제조 사양서(technical specification) 전달까지 하나의 워크플로우.
- 핵심 기술: 제조사가 서로 다른 이기종 부품(용기·캡·펌프 등)의 결합 가능성(호환성)을 자동 분석·추천.
- 해결하려는 문제: 기존 협업은 이메일·문서·실물 샘플 중심 → 반복 수정, 샘플 제작, 제조사 소통 비효율.
- 2025.6.24 아모레퍼시픽과 MOLDWORK 정식 공급 계약 (2025.7.10 발표). 신제품 기획, 용기 디자인, 마케팅 시각화에 활용 계획. 제품 기획 → 3D 시뮬레이션 실시간 검증 → 생산 연계 → 디지털 커머스까지의 협업 모델.
- 2026.6.17~20 파리 VIVATECH 2026 출품. 로레알, 샤넬, LVMH 관계자 부스 방문 (회사 측/언론 보도). 로레알 공급 용기 기반 "MOLDWORK 데모 버전" 제공해 로레알 본사와 프로젝트 가능성 논의 계획. 프랑스에서 PoC 추진 계획 (명희상 책임 인터뷰).
- 한 프랑스 기사: 리드타임 50% 이상 단축(회사 주장 수치), 2026.5부터 아모레퍼시픽 브랜드 전반에 도입, LG생활건강 포함 국내 고객 17곳 (단일 기사 — 확인 필요).
